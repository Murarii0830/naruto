# Anime Nexus — Streamlit

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

1. Push `app.py`, `requirements.txt`, and optionally `anime_nexus_data.json` to GitHub.
2. Create a Streamlit Cloud app.
3. Select `app.py` as the main file.
4. Deploy.

Do NOT put `tkinter`, `ttk`, or `messagebox` in requirements.txt.
